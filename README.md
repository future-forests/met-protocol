# FF-MET-042 field protocol (class exercise)

Starter repository for **Exercise D** in Class 2 (*Git and collaboration*).

## For students

1. Clone this repository (SSH URL from your instructor or course materials).
2. `git checkout main` and `git pull`.
3. Create a branch named on your **rule card** (e.g. `protocol/rain-events`).
4. Add **only your assigned bullet** to `protocol_staufen.md`.
5. Commit, push, and open a **Pull Request** into `main`.

Do not push directly to `main`.
